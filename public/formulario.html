¿Qué caso es?

Compara el empuje Fₐ con la resistencia Fᵣ y mira si el carro ya se movía (v₀).

Si…CasoQué pasa
v₀ = 0 y Fₐ > FᵣArranqueSale del reposo y acelera. Supuesto: el empuje supera la fricción estática máxima.
v₀ > 0 y Fₐ > FᵣArranque*Ya se movía y sigue acelerando: mismas fórmulas, pero con v₀.
v₀ > 0 y Fₐ < FᵣFrenadoFrena, se detiene y se queda quieto. No retrocede.
Fₐ = Fᵣ (y v₀ > 0)EquilibrioFuerza neta cero: sigue a la misma velocidad.
v₀ = 0 y Fₐ ≤ FᵣQuietoNo arranca: la fricción estática iguala al empuje. a = 0, nada se mueve.

Para todos los casos

Fuerzas

P = m·gpeso (g = 9,8 m/s²)
N = Pnormal: se anula con el peso
Fneta = Fₐ − Fᵣlo que sobra
a = Fneta / m2.ª ley de Newton
Fₛ,máx = μₛ·Nlo máximo que aguanta la fricción estática
Fᵣ = μ·Nroce si te dan el coeficiente cinético μ

DCL: siempre 4 fuerzas. Fₐ →, Fᵣ ←, P ↓, N ↑.

Movimiento (a constante)

v = v₀ + a·tvelocidad en el instante t
x = x₀ + v₀·t + ½·a·t²posición en el instante t
Δx = x − x₀cuánto avanzó
v² = v₀² + 2·a·Δxcuando no te dan el tiempo
Δx = ½·(v₀ + v)·tcuando conoces las dos velocidades

Energía y trabajo

K = ½·m·v²energía cinética
ΔK = K − K₀lo que ganó o perdió
W = F·Δx·cos θtrabajo (θ: ángulo con el movimiento)
Wₐ = Fₐ·Δxempuje: positivo
Wᵣ = −Fᵣ·Δxroce: negativo
Wₚ = Wₙ = 0perpendiculares al movimiento
Wneto = Wₐ + Wᵣ = ΔKteorema trabajo-energía

Las tres hojas de casos

Arranque

v₀ = 0 y Fₐ > Fᵣ

Fuerzas

a = (Fₐ − Fᵣ) / mpositiva

Movimiento

v = a·tparte de v₀ = 0
Δx = ½·a·t²

Si te dan la distancia Δx

t = √(2·Δx / a)cuánto tarda
v = √(2·a·Δx)con qué llega

Energía

K₀ = 0empieza quieto
K = ½·m·v²
Wₐ = Fₐ·Δx
Wᵣ = −Fᵣ·Δx
(Fₐ − Fᵣ)·Δx = KWneto = ΔK

Despejes útiles

Fₐ = Fᵣ + m·aempuje para lograr una aceleración
a = 2·Δx / t²para recorrer Δx en un tiempo t

Ojo: para saber si arranca hay que comparar con Fₛ,máx = μₛ·N, no con Fᵣ. Sin ese dato, se supone que arranca y se dice. Si ya se movía (v₀ > 0), usa v = v₀ + a·t y Δx = v₀·t + ½·a·t².

Frenado

v₀ > 0 y Fₐ < Fᵣ

Fuerzas

a = (Fₐ − Fᵣ) / mnegativa

Cuándo y dónde para

tₚ = v₀ / |a|tiempo de parada
d = v₀² / (2·|a|)distancia de frenado
d = v₀·tₚ / 2otra forma
d = ½·m·v₀² / (Fᵣ − Fₐ)con energía

Antes de parar (t < tₚ)

v = v₀ + a·t
x = x₀ + v₀·t + ½·a·t²

Después de parar (t ≥ tₚ)

v = 0se queda quieto: no retrocede
x = x₀ + dse queda donde paró

Energía

ΔK = −½·m·v₀²pierde toda su energía
Wᵣ = −Fᵣ·d
Wₐ = Fₐ·dcero si nadie empuja
Wₐ + Wᵣ = ΔK

Despejes útiles

Fᵣ = Fₐ + m·v₀² / (2·d)resistencia para parar en d

Ojo: si te piden un tiempo mayor que tₚ, no uses v = v₀ + a·t: daría negativa. Si te piden recorrer Δx, solo lo logra si Δx ≤ d.

Equilibrio

Fₐ = Fᵣ

Fuerzas

Fneta = 0
a = 0

Movimiento

v = v₀constante (1.ª ley de Newton)
Δx = v₀·t
t = Δx / v₀si te dan la distancia

Energía

K = K₀ = ½·m·v₀²
ΔK = 0
Wₐ = Fₐ·Δx
Wᵣ = −Fᵣ·Δx = −Wₐel roce saca lo que mete el empuje
Wneto = 0

Ojo: fuerza neta cero no es quieto: es velocidad constante. Solo si v₀ = 0 se queda quieto (no arranca).

Receta y errores frecuentes

Receta en 7 pasos

  1. Dibuja el DCL con las 4 fuerzas.
  2. Fuerza neta: Fₐ − Fᵣ.
  3. Aceleración: a = Fneta / m. Mira el signo para saber el caso.
  4. Movimiento: t, v y x con las fórmulas de su hoja. Si frena, primero calcula tₚ.
  5. Energía: K₀, K y ΔK.
  6. Trabajos: Wₐ, Wᵣ y Wneto. Comprueba que Wneto = ΔK.
  7. Conclusión en una frase, con unidades.

Errores frecuentes

  • Olvidar el ½ en x = ½·a·t² y en K = ½·m·v².
  • Poner Wᵣ positivo: el roce siempre hace trabajo negativo.
  • Usar v = v₀ + a·t después de que el carro se detuvo.
  • Dejar la masa en gramos: 500 g = 0,5 kg.
  • Usar Fᵣ para decidir si arranca: se necesita Fₛ,máx.
  • Olvidar las unidades: N = kg·m/s² y J = N·m.
