Fundamentación física del simulador Carril

Modelo, supuestos, ecuaciones y decisiones de modelación. Física Mecánica, Universidad Cooperativa de Colombia, 2026-2.

1. Sistema físico

Un cuerpo de masa m se mueve en una sola dimensión sobre un carril horizontal (eje x, positivo hacia la derecha). Sobre él actúan una fuerza aplicada Fₐ hacia +x y, mientras desliza en ese sentido, una fuerza resistiva Fᵣ que se opone al movimiento. En la vertical actúan el peso y la normal.

2. Supuestos del modelo

  • Fuerzas horizontales constantes en cada tramo del movimiento.
  • Masa constante; el cuerpo se trata como partícula.
  • Movimiento rectilíneo sobre un carril horizontal: el peso y la normal se compensan.
  • Fᵣ es una fuerza resistiva cinética: solo actúa mientras el cuerpo desliza.
  • El cuerpo está en reposo o se mueve hacia +x (v₀ ≥ 0).
  • g = 9,8 m/s². Solo se usa para el peso y la normal; no afecta los resultados horizontales.

4. Ecuaciones del modelo

Eje vertical (no hay aceleración vertical):

N − P = 0  →  N = P = m·g

Eje horizontal, segunda ley de Newton mientras el cuerpo desliza hacia +x:

Fₐ − Fᵣ = m·a  →  a = (Fₐ − Fᵣ) / m

Con fuerzas constantes la aceleración es constante en cada tramo, y valen:

v(t) = v₀ + a·t     x(t) = x₀ + v₀·t + ½·a·t²

Frenado hasta el reposo (a < 0). Se detiene cuando v = 0:

tp = v₀ / |a|     Δxp = v₀² / (2·|a|)

Para t > tp permanece en reposo: v = 0, a = 0 y x constante.

Tiempo para recorrer un Δx dado: se despeja t de la ecuación de posición.

½·a·t² + v₀·t − Δx = 0  →  t = (−v₀ + √(v₀² + 2·a·Δx)) / a  (si a = 0: t = Δx / v₀)

Si v₀² + 2·a·Δx < 0, el cuerpo se detiene antes de recorrer Δx.

Energía cinética y trabajo de una fuerza constante (θ es el ángulo entre la fuerza y el desplazamiento):

K = ½·m·v²     W = F·Δx·cos θ

Teorema trabajo-energía. Con aceleración constante, v² = v₀² + 2·a·Δx. Entonces:

Wneto = Fneta·Δx = m·a·Δx = ½·m·v² − ½·m·v₀² = ΔK

Solo hay desplazamiento mientras el cuerpo desliza; en reposo Δx = 0 y ninguna fuerza hace trabajo.
